Useful Code: Ready-to-Use Examples by Level

Learn safe, practical snippets for everyday system tasks, automation, diagnostics and more advanced maintainable scripts.

Study in order, practise in a lab you own or have explicit permission to test, take notes, and revisit each level. Examples are educational; never run security tests against systems without authorization.

Level 1 — Everyday commands

Start with commands that inspect information rather than changing the system.

pwd

df -h

uptime

# Windows PowerShell

Get-ChildItem

Level 2 — Python system summary

import platform
from datetime import datetime

print("OS:", platform.system(), platform.release())
print("Machine:", platform.machine())
print("Python:", platform.python_version())
print("Time:", datetime.now().isoformat(timespec="seconds"))

Level 3 — Safe folder inventory

from pathlib import Path

root = Path("practice-files")
root.mkdir(exist_ok=True)

for item in sorted(root.iterdir()):
    if item.is_file():
        print(f"{item.name}: {item.stat().st_size} bytes")
    elif item.is_dir():
        print(f"{item.name}/ [directory]")

Level 4 — Hash files for integrity

from pathlib import Path
import hashlib

def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        for chunk in iter(lambda: stream.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()

sample = Path("sample.txt")
if sample.is_file():
    print(sha256_file(sample))
else:
    print("Create sample.txt first.")

Level 5 — Read and summarize a log

from pathlib import Path
from collections import Counter

path = Path("sample.log")  # use a copied lab log
if path.is_file():
    counts = Counter(line.split()[0] for line in
                     path.read_text(errors="replace").splitlines()
                     if line.split())
    for token, count in counts.most_common(10):
        print(count, token)
else:
    print("Put a sample log beside this script.")

Level 6 — Robust script patterns

#!/usr/bin/env python3
import argparse
import logging
from pathlib import Path

parser = argparse.ArgumentParser(description="Count files in a folder")
parser.add_argument("folder", type=Path)
args = parser.parse_args()
logging.basicConfig(level=logging.INFO, format="%(levelname)s: %(message)s")

if not args.folder.is_dir():
    parser.error("folder must be an existing directory")

files = [p for p in args.folder.iterdir() if p.is_file()]
logging.info("Found %d files", len(files))

Level 7 — Testing and maintenance

  • Add type hints, docstrings, clear errors and meaningful exit codes.
  • Use a virtual environment and pin dependencies for repeatable runs.
  • Write unit tests for empty folders, permission errors, unusual filenames and missing input.
  • Prefer dry-run mode before file modifications; create backups for destructive operations.
  • Never hardcode passwords/API keys or disable certificate verification to “fix” TLS errors.

Level 8 — Advanced project ideas

  1. Log analyzer that redacts IPs or usernames where required.
  2. Backup verifier that checks hashes and restore procedures.
  3. Local service health checker with explicit host allowlists, timeouts and low request rates.
  4. Configuration audit that reports risky settings without changing them automatically.
  5. Package a command-line tool with tests, CI, documentation and versioning.
Before running any script, read it, understand which files or services it touches, and test against disposable sample data first.
