Python: Beginner to Advanced Roadmap

A level-by-level Python course with runnable examples, core concepts, projects, testing, automation and safe security scripting.

Study in order, practise in a lab you own or have explicit permission to test, take notes, and revisit each level. Examples are educational; never run security tests against systems without authorization.

Level 1 — First steps

Python is a readable, general-purpose language used for automation, web apps, data work, testing and security tooling. Install Python 3 from the official source and verify with python --version or python3 --version.

print("Hello, world!")
name = input("Your name: ")
print(f"Welcome, {name}!")

Level 2 — Types and variables

name = "Asha"       # str
age = 14            # int
score = 9.5         # float
is_learning = True  # bool
print(type(age))
print(f"{name} is {age} years old")

Learn strings, integers, floats, booleans, None, conversion, operators, comparisons and f-strings.

Level 3 — Decisions and loops

score = 82

    grade = "B"

Level 4 — Collections

Study list, tuple, set, dictionary, indexing, slicing, comprehensions and choosing the right structure.

Level 5 — Functions and modules

def calculate_total(price, quantity=1):
    if price < 0 or quantity < 0:
        raise ValueError("Values must be non-negative")
    return price * quantity

print(calculate_total(12.5, 3))

# Import a standard-library module
import math
print(math.sqrt(81))

Learn parameters, return values, scope, docstrings, imports, packages and clean project structure.

Level 6 — Files, errors and data

from pathlib import Path

path = Path("notes.txt")
path.write_text("Learn safely.\n", encoding="utf-8")
print(path.read_text(encoding="utf-8"))

try:
    value = int("123")
except ValueError:
    print("Input must be an integer")

Use with open(...) for file handles, JSON/CSV modules for structured data, and catch specific exceptions. Validate user input and avoid logging secrets.

Level 7 — OOP and type hints

from dataclasses import dataclass

@dataclass
class Device:
    hostname: str
    ip_address: str
    managed: bool = True

lab_pc = Device("lab-pc", "192.168.56.10")
print(lab_pc.hostname)

Learn classes, composition, inheritance only when useful, dataclasses, type hints, iterators, generators and context managers.

Level 8 — Professional Python

  • Virtual environments: python -m venv .venv; activate using your OS-specific command.
  • Dependencies, pinned versions, packaging, project layout and reproducible builds.
  • Testing with unittest or pytest; test normal, boundary and error cases.
  • Debugging, logging, profiling, code review, linting and formatting.
  • HTTP APIs with timeouts, retries and careful handling of credentials.
  • Concurrency: understand asyncio, threads and processes before choosing one.
  • Databases, SQL parameters, transactions and schema migrations.

Level 9 — Safe automation project

Build a local file inventory tool. It reads filenames and sizes from a folder you choose and writes a CSV report. It does not alter or upload files.

from pathlib import Path
import csv

root = Path("practice-files")
output = Path("inventory.csv")
root.mkdir(exist_ok=True)

with output.open("w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "bytes"])
    for item in sorted(root.iterdir()):
        if item.is_file():
            writer.writerow([item.name, item.stat().st_size])

print(f"Report written to {output.resolve()}")

Create a few sample files inside practice-files, run the script and inspect the CSV.

Level 10 — Advanced topics

Study decorators, descriptors, protocols, advanced typing, async I/O, profiling, memory behavior, secure deserialization, cryptographic library usage, CI, packaging and API design. For security work, practise parsing logs, validating URLs, checking file hashes and interacting with lab APIs—never build tools for unauthorized access.

Recommended capstone sequence

  1. CLI calculator and quiz.
  2. File organizer with dry-run mode and tests.
  3. Log summarizer with CSV/JSON output.
  4. HTTP status checker for a list of explicitly authorized lab URLs, with timeouts and rate limits.
  5. Package one project with README, tests, error handling and a clear license.
