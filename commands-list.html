Commands List: Linux, Windows and Other Systems

A categorized quick reference for common operating-system commands, with notes on differences between shells.

Study in order, practise in a lab you own or have explicit permission to test, take notes, and revisit each level. Examples are educational; never run security tests against systems without authorization.

Linux / Unix / macOS (Terminal)

Navigation and files

pwd
ls -lah
cd /path
mkdir folder
touch file.txt
cp source.txt copy.txt
mv old.txt new.txt
rm file.txt
find . -name "*.log"
grep -R "error" ./logs

Careful: rm deletes files; verify paths before use.

Permissions and packages

chmod 640 file.txt
chown user:group file.txt
sudo apt update
sudo apt install package-name

Package commands differ: Debian/Ubuntu use apt; Fedora uses dnf; Arch uses pacman; macOS commonly uses built-in tools or Homebrew.

Some commands need administrator rights or additional tools. Review official documentation before changing services, disks or network settings.

Android, iOS and other systems

Android: Settings provides most user administration. Android Debug Bridge (ADB) is a developer tool and requires explicit device authorization.

adb devices
adb shell getprop ro.build.version.release

iOS/iPadOS: most tasks use Settings and device-management tools; shell access is not generally exposed on a standard device. Use official Apple support and developer documentation.

BSD: many Unix commands are similar, but service management, package managers and networking syntax can differ by FreeBSD/OpenBSD version.

Containers: Docker and Kubernetes have their own command sets; learn them separately and operate only on your own environment.

Command safety habits

  • Use --help or man command (Linux/macOS) and Get-Help (PowerShell).
  • Check current directory, target path and privileges before write/delete commands.
  • Do not paste unknown commands from the internet into an administrator shell.
  • Use read-only inspection first; make backups before system changes.
  • Commands and flags vary by OS version and shell; this is a practical starter reference, not literally every command available.
